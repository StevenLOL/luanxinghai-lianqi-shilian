# 010 产品设计方案：仙侠剑仙游戏

> 阶段：产品设计（GDD 简版）。时间 2026-11-17 15:33 GMT+8。
> 输入：`docs/007` 需求与决策；依据：`docs/008` 调研报告（路线 B 已确认）、`docs/009` 实施规格。
> 本文件定义**玩什么、怎么玩、数值怎么走**；技术实现见 `docs/009`，不在此重复。

---

## 0. 产品一句话

> **一款"踩着飞剑亲自游历山海"的国风修仙游戏：野外遇敌就落入伪 3D 空间斗法，打完回宗门炼丹炼器，突破境界后飞得更远。**

三个不可替代的体验钩子（其余都是支撑）：

1. **飞行是真操作**，不是点地图传送——自己驾驭飞剑穿过云海、越过山脊。
2. **斗法有空间感**——站位、高度、法术范围、队友协同同时起作用，不是站桩对轰。
3. **宗门是前线供给**——这一炉丹、这一张符，直接决定下一次出门能打谁。

---

## 1. 目标用户与平台

| 项 | 定义 |
|---|---|
| 核心用户 | 喜欢修仙成长与山海题材、但嫌传统仙侠"只有数值没有操作"的玩家；能接受轻度战术思考 |
| 参考画像 | 玩过鬼谷八荒/碧海苍云录的成长感，又想要一点 RTS 站位的人 |
| 首发平台 | 按 `docs/008` 待拍板项：PC(Steam) / Android / Web。设计本身按**键鼠 + 触屏双输入**预留 |
| 单局时长 | 1 次游历循环 10~20 分钟；完整周目目标 30~60 分钟（MVP） |
| 付费模式 | 建议买断制；无抽卡（对齐碧海苍云录的信任感） |

## 2. 核心循环

### 2.1 双相循环

```text
[宗门相] 接任务 / 炼丹 / 炼器 / 画符 / 学功法 / 升级建筑
   │  产出：丹药、法器、符箓、技能槽、队伍配置
   ▼
[大地图相] 御剑飞行 / 步行 / 找 POI / 遇敌 / 切视角
   │  触发：EncounterSpec（地形、种子、敌人组、天气）
   ▼
[斗法相] 伪3D空间战术：指挥队友、剑诀、区域法术、高度差
   │  产出：BattleResult（战利品、修为、声望、世界标记）
   ▼
[结算回流] 材料入库 → 新配方 / 新境界 → 回宗门相
```

### 2.2 十分钟体验脚本（设计基准）

| 时间 | 玩家动作 | 系统反馈 | 情绪目标 |
|---|---|---|---|
| 0-2 min | 山门接任务"北溟妖兽扰灵田"，选 2 队友、带 3 张雷符 | 任务板标 POI；背包预扣符位 | 目标明确 |
| 2-4 min | 御剑飞越云海，切 45°/70° 找山谷入口 | 飞行耗灵力；高处视野更远 | 自由、辽阔 |
| 4-7 min | 落入斗法：队友牵制，玩家放雷池+剑诀 | 妖兽冲锋、敌修放符；山挡低空弹道 | 紧张、有决策 |
| 7-9 min | 击败妖兽，队友负伤，捡妖丹/鳞片 | 掉落入库；队友状态带入结算 | 收获 |
| 9-10 min | 回宗门炼丹、突破筑基，解锁"御剑斩" | 新技能进技能栏；新区域解锁 | 成长、想再来一次 |

**这个脚本是设计的"北极星"**：任何系统若不服务于这 10 分钟，就推迟到 P5 之后。

## 3. 系统设计

### 3.1 境界系统

境界是整个游戏的**主进度轴**，不是数字标签。每次突破必须同时改变三件事，否则玩家无感：

| 境界 | 斗法解锁 | 探索解锁 | 宗门解锁 | 战斗乘数 |
|---|---|---|---|---|
| 练气 | 走位、低阶符、1 个剑诀 | 只能步行；低空禁区不可进 | 外门弟子；基础丹房 | 1.0 |
| 筑基 | 飞剑连击、短距突进、罡气 | 低空御剑；越浅山 | 内门弟子；接下阶任务 | 1.4 |
| 金丹 | 区域法术（雷池/火域）、法宝 | 高空御剑；云海/海面通行 | 执事；开炉炼中阶丹 | 2.0 |
| 元婴 | 元婴出窍（分身/远观）、瞬移剑 | 跨区快速飞行；秘境入口 | 长老；授徒、开大比 | 2.8 |
| 化神 | 领域展开、神兽契约、剑阵 | 地图边界扩展；天气免疫 | 宗主候选 | 4.0 |

**突破规则：**

- 条件 = 修为达标 + 突破丹 + 闭关时间（可选）+ **心魔劫/天劫小关卡**（至少其一，建议从金丹起必带）；
- 代价：失败损失部分修为与材料，不损失境界；
- 乘数刻意保守（1.0→4.0），强弱差距靠**机制解锁**而非数值碾压（吸取 carefree 10→100→1000 的教训）；
- 五行灵根影响功法适配与克制，不做"极品灵根碾压"（吸取碧海苍云录的灵根失衡反馈）。

### 3.2 斗法系统

**规模**：玩家 1（剑仙）+ 队友 2~3 vs 敌人 3~6；神兽 Boss 战单独设计。

**单位原型（首版 6 类）：**

| 单位 | 定位 | 行为 | 威胁点 |
|---|---|---|---|
| 玩家剑仙 | 飞行/输出/指挥 | 御剑移动、剑诀、区域法术、下令 | 核心动词载体 |
| 剑修队友 | 近战牵制 | 贴身、挡刀、连击 | 保护后排 |
| 丹修/符修队友 | 治疗/符箓 | 回血、增益、补符 | 续航与容错 |
| 猛兽 | 冲锋 | 直线突进、扑击、畏火雷 | 近场压迫 |
| 人类敌修 | 远程 | 放符、走位、集火玩家 | 反制玩家站位 |
| 神兽（Boss） | 多阶段 | 跨层攻击、地形互动、阶段转换 | 高潮体验 |

**法术槽（首版 6 个）：**

| 法术 | 形态 | 作用 | 解锁境界 |
|---|---|---|---|
| 弹道剑诀 | 直线弹道 | 单体，低耗灵 | 练气 |
| 护体罡气 | 自身/友方 | 短时减伤/反弹 | 筑基 |
| 瞬移剑 | 位移+路径伤害 | 切入/逃生 | 筑基 |
| 雷池 | 圆形区域，持续 tick | 控场+地面状态 | 金丹 |
| 符箓爆发 | 一次性高威力 | 宗门产出，战术牌 | 练气（受符箓库存限制） |
| 法宝领域 | 持续区域增益/压制 | 法宝驱动 | 金丹以上 |

**高度层**：GROUND / LOW_AIR / HIGH_AIR / SKY。山挡低空弹道，海面减速地面单位但利神兽，雷池只打 GROUND，剑气可打 LOW_AIR。这是"空间感"的主要来源。

**操作映射（键鼠 + 触屏）：**

| 动作 | 键鼠 | 触屏 |
|---|---|---|
| 移动/御剑 | WASD / 鼠标指向 | 左虚拟摇杆 |
| 相机 yaw | 右键拖动 | 空白处单指拖动 |
| 相机 pitch | 滚轮（三档） | 双指上下 |
| 法术 | 1~6 | 屏幕技能按钮 |
| 选中队友/下令 | Tab / 数字+右键 | 点队友头像再点地面 |
| 闪避 | 空格 | 独立按钮 |

**AI 要求**：队友跟随/集火/保护三态可切换（玩家下令覆盖）；敌人按原型有独立状态机；Boss 阶段化脚本。

### 3.3 大地图探索

- **结构**：分区块高度场 + POI 图，不是无缝全球。首版 1 山区 + 1 海域。
- **步行 vs 飞行**必须可感知地不同：

| 维度 | 步行 | 飞行 |
|---|---|---|
| 速度 | 慢 | 快 |
| 地形 | 走导航网格 | 可越部分障碍 |
| 灵力 | 不耗 | 持续消耗 |
| 采集 | 可采灵草/矿 | 不可采（需落地） |
| 视野 | 正常 | 半径增大 |
| 风险 | 低遇敌率 | 高空可能被发现 |

- **POI 类型**：秘境、宝箱、NPC、妖兽据点、灵脉、传送阵、奇遇触发点。
- **相机**：跟随 + 三档俯角（25/45/70），与斗法层共用同一套 rig（`docs/009` §2.5）。

### 3.4 宗门系统

首版四条生产链，每条必须**产出直接影响斗法**：

| 链 | 输入 | 输出 | 斗法影响 |
|---|---|---|---|
| 炼丹 | 灵草+妖丹+炉火 | 突破丹/疗伤丹/灵力丹 | 突破门禁、续航 |
| 炼器 | 矿石+妖兽材料 | 飞剑/护甲/法宝 | 改技能与属性 |
| 画符 | 符纸+灵墨+兽血 | 雷符/火符/护符 | 一次性战术牌 |
| 功法 | 残页+悟性+时间 | 心法/剑诀/身法 | 解锁新技能槽 |

**建筑**：丹房、器阁、符堂、藏经阁、灵田、演武场、传送阵。升级建筑提升产能上限与配方等级。

**弟子**：首版只做"可派遣采集/护送"的功能性弟子，不做完整社交模拟（那是了不起的修仙模拟器的护城河，不碰）。

**防通胀**（针对碧海苍云录"作业感"反馈）：

- 高级材料按境界区域门禁；
- 丹药耐药性、符箓携带上限；
- 炼制失败产"杂质"，可降级再利用；
- 重复战斗提供**扫荡/跳过**，但核心遭遇必须手动。

### 3.5 经济系统

```text
产出：战斗掉落 + 地图采集 + 宗门生产 + 任务奖励
消耗：丹药/符箓消耗 + 法器升级 + 突破材料 + 建筑升级
```

关键约束：**每样资源都有明确 sink（消耗口）**，避免"刷完不知道干嘛"。境界门禁是控制产出节奏的主阀门。

### 3.6 叙事与任务

- **轻叙事**：主线任务板 + 奇遇文本 + NPC 对话，不做重剧情演出（避免与近景演出绑定，符合路线 B 的镜头限制）。
- **任务类型**：主线（推进境界/区域）、宗门任务（产出资源）、奇遇（随机事件）、挑战（龙主/堕仙类爬塔，可扫荡）。
- **世界状态**：用 flags 记录关键选择（如放过/击杀某妖兽），轻度影响后续遭遇。

## 4. 数值框架（首版基线）

| 项 | 规则 |
|---|---|
| 伤害公式 | `基础攻击 × 境界乘数 × 技能系数 × 克制系数 × (1 - 防御减免)` |
| 五行克制 | 金木水火土相克；克制 +30%，被克 -20%（不搞倍杀） |
| 境界乘数 | 1.0 / 1.4 / 2.0 / 2.8 / 4.0（练气→化神） |
| 灵力 | 飞行与法术共用池；地面静止缓慢回复 |
| 掉落 | 妖兽材料（炼器/画符）、妖丹（炼丹）、灵石（通用）、功法残页（技能） |
| 稀有度 | 白/绿/蓝/紫/橙；词条随机但可转移/升阶（对齐碧海苍云录的保值设计） |

**调优原则**：先让 10 分钟脚本跑通，再调数值；不要用数值掩盖玩法问题。

## 5. UI/UX 设计

| 界面 | 核心信息 | 交互要点 |
|---|---|---|
| 大地图 HUD | 小地图、灵力条、生命条、境界、任务追踪 | 飞行/步行状态显式标识 |
| 斗法 HUD | 技能栏(6)、队友状态+指令、敌方血条、高度层指示、法术范围预览 | 范围预览必须有地面投影圈 |
| 宗门面板 | 建筑列表、生产队列、背包、功法树、任务板 | 生产可排队、可一键收取 |
| 角色/境界 | 灵根、境界进度、突破条件、已解锁动词 | 突破条件缺什么一目了然 |
| 图鉴 | 妖兽/神兽/功法/法宝 | 收集驱动探索 |

**视觉语言**：水墨国风 + 留白；主色玉青/朱砂/描金；禁用霓虹赛博色（避免 carefree 的风格漂移问题）。字体用毛笔体做标题、宋体做正文。

## 6. 新手引导（前 10 分钟）

1. **0-1 min**：直接给飞剑，教"飞起来"——不弹教程弹窗，用地面光带引导；
2. **1-3 min**：第一次遭遇，只给 1 个剑诀，教"点地面放法术"；
3. **3-5 min**：队友加入，教"点头像下令"；
4. **5-7 min**：打赢，掉落入库；
5. **7-10 min**：回宗门炼丹、突破筑基，解锁新动词——**用成长作为引导的收尾奖励**。

原则：引导即玩法，不单独做教程关。

## 9. 待用户拍板的问题

1. **首发平台**：PC / Android / Web 哪个先？影响输入与性能预算。
2. **斗法规模**：3v5 小队战术，还是 10v10 排兵布阵？本设计按前者写。
3. **美术来源**：自绘 / 外包 / AI 辅助 / 改 fighter 资产？决定路线 B 能撑多久。
4. **境界上限**：元婴收尾还是做到化神？本设计做到化神。
5. **叙事强度**：轻任务板（本设计）还是重主线剧情？

## 10. 设计红线（来自竞品差评的教训）

| 不要 | 原因 |
|---|---|
| 境界到了却"不能怎么样" | 碧海苍云录"成就空心化"反馈 |
| 清本像写作业、不能扫荡 | 碧海苍云录"繁琐拖沓"反馈 |
| 系统解锁晚于需求（穿6阶装才开1阶锻造） | 碧海苍云录"系统错位"反馈 |
| 灵根/道途投入与收益倒挂 | 碧海苍云录"3灵根不如5灵根废物"反馈 |
| 伤害 10→100→1000 指数膨胀 | carefree 的数值教训 |
| 无抽卡却处处卡资源 | 碧海苍云录"不课很累"反馈 |
| 霓虹赛博色混进水墨 | carefree 风格漂移 |

## 11. 一句话收尾

**产品设计的全部赌注，押在"飞过去、打一仗、带点东西回来变强"这 10 分钟上；系统再多，也要先让这 10 分钟成立。**
