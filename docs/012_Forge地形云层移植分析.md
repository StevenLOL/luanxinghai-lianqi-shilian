## 2. 当前 MVP 与 Forge 的差异

| 维度 | 当前 MVP v2.3 | Forge |
|---|---|---|
| 渲染方式 | Canvas2D 多边形透视投影，实时画 ±390 网格 | 低分辨率 `Uint32Array` 帧缓冲 + 逐像素软件光栅 |
| 地形 | 连续正弦高度函数 + 平滑颜色插值 | 噪声高度图 + 离散阶梯 + 材质/侧面/阴影 |
| 海洋 | 深/浅蓝 + 正弦波纹 | 4 级海色 + 浪花材质 + 波光闪烁 + 泡沫 |
| 云 | 26 组随机椭圆，高度 52~110，偏“棉团” | 云图 puff 簇，固定在 `CLOUD_ALT=40` 附近，有厚度与底面，贴地/贴海 |
| 天空 | 三段渐变 + 太阳 + 山影 | 八段渐变 + 地平线雾 + 太阳/月亮/星空 |

结论：**不能逐行照搬 `drawWorld()`**，否则要重写投影、深度缓冲、碰撞高度与所有坐标；成本远超本次视觉需求。

## 3. 移植策略（采用）

做“视觉与数据风格移植”，不是“渲染器移植”：

1. **地形高度**：保留 `terrainH(x,z)` 的接口与量级，但内部改为 4~5 octave 值噪声 + 阶梯量化，让山体出现 Forge 式台地。
2. **材质映射**：新增 `forgeMat(h,c,x,z)`，输出 Forge 17 材质索引；渲染时按顶面/侧面两套颜色，草地加明暗条纹，海面深中浅三级 + 浪花点。
3. **海面**：保留安全区语义（海面无妖兽、灵力快充），视觉改 Forge 蓝：深海 `[36,104,180]`、浅海 `[66,160,216]`、浪花 `[104,204,214]`，并保留动画波光。
4. **云层**：用 Forge 式 puff cluster 生成低位云图：每朵云由 4~10 个圆 puff 拉成带，云有 `top/side/under` 三色与厚度层；在当前透视投影下画成一组扁平叠片，而不是大椭圆。
5. **天空/雾**：天空换 Forge 八段蓝色渐变；远处地形按距离混入淡蓝雾色 `[188,224,246]`，接近 Forge 地平线。
6. **不变**：法术、视野、自动攻击、投射物物理、敌人 AI、HP 自愈、素材加载与操作键位全部不动。

## 4. 验收标准

- 截图对比：能明显看出“绿色阶梯岛 + 沙滩 + 蓝色海面 + 低位白色云带 + 淡蓝远雾”。
- 逻辑回归：v2.2 的 T1–T10 与 v2.3 的 V1–V8 关键断言仍通过，尤其 `terrainH` 接口、海面判定、敌人生成、投射物落地。
- 性能：不引入每帧大数组重生成；云与地形噪声只在初始化/重置时生成。
- 兼容：仍是单 HTML、`file://` 双击可玩。

## 6. 后续补遗：切云效果（v2.6，2026-11-18 11:05）

- 用户追加要求主角穿云时也要有 Forge 切云效果。回到源码 L1535-1570 `cutCloud()` 与 L1571-1623 `stepClouds()` 精确定位：Forge 以 `CUT_HEAL=11s` 维护环形 cut 队列，飞机在云层高度时把半径 `r` 内的云格清空，边缘薄化，并在入云瞬间喷出 14 股 vapour。
