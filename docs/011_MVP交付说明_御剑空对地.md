## 1. 如何运行

**双击 `scripts/mvp_air_to_ground.html` 即可**，无需服务器、无需联网、无外部依赖。

- 单文件 HTML，内联全部 JS/CSS；
- 没有 ES module / importmap / fetch，所以 `file://` 下可运行（避开 `docs/005` 的 CORS 坑）；
- 浏览器建议 Chrome / Edge。

## 2. 操作

| 动作 | 键鼠 | 说明 |
|---|---|---|
| 移动 | WASD / 方向键 | 相对镜头方向 |
| 降 / 升 | Q / E | 高度 5~130 丈 |
| 剑诀（空对地单体） | 左键 / J | 命中地面目标，26 伤害 |
| 雷池（空对地区域） | 右键 / K | 持续 4 秒的范围伤害 |
| 俯冲斩 | 空格 | 低空高速下压，沿途 46 伤害 |
| 视角切换 | 1 / 2 / 3 | 25° / 45° / 70° 俯角 |
| 重来 | R | — |

点击开始；气血归零后按 R 或点击重来。

## 4. 已复现并修复的 bug

**玩家飞剑渲染成巨大青色圆球，挡住画面中心。**

- 根因：玩家离相机近，投影缩放 `s = focal/z` 很大；御剑者半径写成 `(3-i*0.5)*s`、剑身半宽 `2.4*s`，导致世界尺寸被放大成数十像素的色块。
- 修复：御剑者半径改为 `0.75*s` 量级、剑身半宽 `0.7*s`，颜色加深与天空区分。
- 举一反三：所有**跟随相机的近景对象**，绘制尺寸必须按世界单位 × 投影缩放保守取值；不能套用远景对象的系数。写完后必须实际截图看一眼，不能只靠代码审阅。

## 5. 验证记录

- **JS 语法**：`node --check` 通过；
- **运行时逻辑**：Node + mock canvas 跑 6 组场景（飞行/剑诀/雷池/俯冲/切视角/重开），零运行时错误；
- **实际渲染**：无头 Chrome 定帧截图两次，第一次发现上述巨球 bug，修复后第二次确认画面正常（飞剑为合理小尺寸、妖兽/地形/HUD 均正常）。

这些属于 P1~P5，见 `docs/008` 路线图与 `docs/010` 产品设计。
