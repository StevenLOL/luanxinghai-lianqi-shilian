# 005 如何运行 `others/local_site` 里的游戏

## 为什么双击 `index.html` 是空白页

实测：用 `file://` 打开 `others/local_site/index.html` 只得到 3.3KB 空白页（正常游戏截图 185KB）。两个原因：

1. **路径**：`index.html` 用根绝对路径 `/src/main.tsx`、`/vendor/...`、`/fragment-host/...`。在 `file://` 下这些被解析到盘符根目录（如 `C:/src/main.tsx`），文件根本不在那里。
2. **协议（更根本）**：游戏是 ES module + importmap 结构，`file://` 协议的 origin 是 `null`，浏览器 CORS 策略会拦截所有模块加载。**任何这类模块化网页都无法靠双击 HTML 运行**，这是浏览器安全限制，不是文件损坏。

结论：必须经 HTTP 提供。游戏本身没问题（在线版、本地 HTTP 版、断网版均已实测截图验证）。

## 方法一（推荐）：双击一键启动

双击运行：

```
C:\src\flight\scripts\05_launch_game.bat
```

它会：启动本地服务（`127.0.0.1:8899`）→ 自动打开默认浏览器进入游戏。玩完在运行窗口按 `Ctrl+C` 或关窗口停止。

> 现在已有一个服务在 `8899` 端口运行（本次验证启动的），直接访问 `http://127.0.0.1:8899/` 就能玩；脚本检测到已运行会复用，不会重复起进程。

## 方法二：命令行

```bash
cd C:/src/flight
python scripts/05_launch_local_game.py
# 或手动：
python scripts/04_local_server.py 8899
# 然后浏览器打开 http://127.0.0.1:8899/
```

## 方法三：任意静态服务器

只要能在 `others/local_site/` 目录起一个 HTTP 服务即可，例如：

```bash
cd C:/src/flight/others/local_site
python -m http.server 8899
```

⚠️ 注意：Python 自带的 `http.server` **不能正确处理 `?module` 查询**（它会把 `engine.mp3?module` 当普通文件返回音频二进制而非 JS 包装），可能导致音效加载失败、部分情况下游戏报错。优先用方法一/二（专用服务器复刻了 Forge 的资源语义）。

## 操作说明（游戏内）

- Space：切换 俯视 / 追尾 / 座舱 视角
- 鼠标移动 / W/S：转向、爬升/俯冲；按住左键或右键：开火
- M：发射导弹
- 触屏设备自动显示屏幕按钮（单指转向、轻点翻滚、Hold Gun/Boost/Missile）
- 首次点击/触摸后才开始播放声音（浏览器自动播放策略）

## 相关文件

- `scripts/05_launch_local_game.py`：一键启动脚本（含原理注释）
- `scripts/05_launch_game.bat`：双击入口
- `scripts/04_local_server.py`：本地服务器（复刻 Forge 资源语义）
- `others/game_launcher_test.png`：一键启动后的实机截图（185,361 B，与在线版逐字节一致）
